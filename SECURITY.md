# Politique de sécurité

## Signaler une vulnérabilité

Merci de **ne pas ouvrir d'issue publique** pour une faille de sécurité.
Utilise la fonction « Report a vulnerability » de l'onglet *Security* du dépôt GitHub (signalement privé).

Délai de première réponse visé : 7 jours.

## Principes appliqués dans ce projet

- Aucun secret dans le code ni dans l'historique Git
- Dépendances surveillées (Dependabot) et code analysé (CodeQL)
- Contrôle d'accès par rôle sur toutes les routes de l'API
- Journalisation des actions sensibles
- Référence : OWASP ASVS niveau 1
